# KidsWorld Design Branding Guidelines

When developing features for the KidsWorld web and mobile applications, act as a product engineer and strictly adhere to the following design constraints:

1. **Icons, not Emojis**: Do not use emojis in the UI. Always use appropriate, consistent UI icons (e.g., Lucide React for web, vector icons for mobile).
2. **No Shadows**: Do not use shadows (`box-shadow`, `elevation`, `drop-shadow`). Keep the interface flat, clean, and modern.
3. **Brand Consistency**: Follow constant design branding guidelines that match the application's core identity. Ensure consistent colors, spacing, and typography across all screens.
